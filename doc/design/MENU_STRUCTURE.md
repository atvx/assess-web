## 路由路径说明

所有后台管理路由都以 `/admin` 为前缀，采用模块化的路径设计：

- **模块/功能**: `/admin/[模块名]/[功能名]`
- **操作页面**: `/admin/[模块名]/[功能名]/[操作]`
- **带参数**: `/admin/[模块名]/[功能名]/[操作]/:id`

### 示例
```
/admin/system/user          # 用户列表
/admin/system/user/create   # 新增用户
/admin/system/user/edit/123 # 编辑ID为123的用户
```

## 技术实现

### 占位页面组件
为了快速搭建菜单结构，未实现的功能使用了统一的占位页面组件：
- **组件路径**: `src/components/common/PlaceholderPage.vue`
- **功能**: 显示页面标题和"功能开发中"提示

### 菜单配置
- **菜单定义**: `src/layouts/AdminLayout.vue`
- **路由配置**: `src/router/admin.ts`
- **图标库**: `@ant-design/icons-vue`

### 已实现功能
1. **用户管理** (完整CRUD)
   - 列表查看、搜索、筛选
   - 新增用户、编辑用户
   - 查看详情、删除用户
   - 重置密码、启用/禁用
   
2. **仪表盘**
   - 基础统计展示
   
3. **基础设置**
   - 系统基础配置

## 开发计划

按照优先级，建议的开发顺序：

1. **第一阶段**: 活动管理 + 参赛者管理
2. **第二阶段**: 评审管理核心功能
3. **第三阶段**: 系统管理完善（角色、权限、菜单）
4. **第四阶段**: 数据管理与报表
5. **第五阶段**: 消息中心与系统设置完善

## 注意事项

1. 所有页面都需要认证才能访问（`requiresAuth: true`）
2. 菜单项的权限控制需要后续配合权限管理模块实现
3. 占位页面只是框架，实际开发时需要替换为真实功能
4. 路由路径已经规范化，后续开发请保持一致性
