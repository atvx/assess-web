# 个人中心设计说明

## 概述

个人中心页面提供完善的个人信息管理、账户安全设置、通知偏好配置和个人数据统计功能。

## 页面布局

### 左侧导航区（6列，约25%）

#### 用户卡片
- **头像**: 显示用户头像（80x80px）
- **姓名**: 显示真实姓名或用户名
- **用户名**: 显示@username格式
- **角色标签**: 管理员标识（蓝色标签）

#### 导航菜单
1. **个人信息** - 管理基本信息和头像
2. **账户安全** - 密码、绑定、设备管理
3. **通知偏好** - 消息订阅和通知方式
4. **我的统计** - 个人活动数据统计

### 右侧内容区（18列，约75%）

## 功能模块

### 1. 个人信息

#### 头像上传
- **功能**: 
  - 点击上传按钮选择图片
  - 支持 JPG、PNG 格式
  - 文件大小限制 2MB
  - 实时预览上传的头像
- **验证**: 自动检查文件类型和大小
- **提示**: 显示支持的格式和大小限制

#### 基本信息编辑
- **用户名**: 不可修改，显示为禁用状态
- **真实姓名**: 可编辑，用于显示真实身份
- **邮箱**: 可编辑，用于接收通知
- **手机号**: 可编辑，用于接收短信
- **个人简介**: 
  - 多行文本输入
  - 最多 200 字符
  - 显示字符计数
  - 支持换行

#### 操作按钮
- **保存修改**: 提交表单数据
- **重置**: 恢复原始数据

### 2. 账户安全

#### 密码修改
- **表单字段**:
  1. 当前密码（必填）
  2. 新密码（必填，6-20位）
  3. 确认密码（必填，需与新密码一致）
- **验证规则**:
  - 所有字段必填
  - 新密码长度验证
  - 新旧密码一致性验证
  - 确认密码匹配验证
- **提交后**: 清空表单，显示成功提示

#### 账号绑定管理
- **支持平台**:
  1. 微信（绿色图标）
  2. 支付宝（蓝色图标）
  3. QQ（天蓝色图标）
- **显示信息**:
  - 平台名称和图标
  - 绑定状态（已绑定/未绑定）
  - 已绑定账号显示账号信息
- **操作**:
  - 未绑定：显示"绑定"按钮
  - 已绑定：显示"解绑"按钮（红色）

#### 登录设备管理
- **设备信息**:
  - 设备类型（MacBook Pro、iPhone等）
  - 浏览器和操作系统
  - 登录位置（IP地址和城市）
  - 登录时间
- **设备标识**:
  - 当前设备：蓝色头像 + "当前设备"标签
  - 其他设备：灰色头像
- **操作**:
  - 当前设备：不可移除
  - 其他设备：显示"移除"按钮（红色）
- **安全功能**:
  - 查看所有登录记录
  - 快速移除异常设备
  - 保护账号安全

### 3. 通知偏好

#### 消息订阅设置
提供5种可订阅的通知类型：

1. **评审任务通知** ✅ 默认开启
   - 有新的评审任务分配时接收通知

2. **活动报名通知** ✅ 默认开启
   - 有新的活动报名时接收通知

3. **系统公告** ✅ 默认开启
   - 接收系统重要公告和维护通知

4. **评审进度提醒** ⭕ 默认关闭
   - 评审进度更新时接收提醒

5. **周报汇总** ⭕ 默认关闭
   - 每周接收工作数据汇总报告

每项配置都有：
- 开关控件（Switch）
- 功能说明文字
- 独立控制

#### 通知方式设置

##### 站内通知
- ✅ 任务提醒
- ✅ 评审通知
- ✅ 系统公告
- ✅ 活动消息

##### 邮件通知
- ✅ 任务提醒
- ✅ 评审通知
- ⭕ 系统公告
- 📧 显示当前邮箱地址

##### 短信通知
- ✅ 紧急任务
- ✅ 安全提醒
- 📱 显示当前手机号

**保存按钮**: 统一保存所有通知偏好设置

### 4. 我的统计

#### 数据统计卡片（4个）
1. **参与活动**: 显示参与的活动总数（蓝色）
2. **完成评审**: 显示完成的评审任务数（绿色）
3. **待办任务**: 显示当前待办任务数（橙色）
4. **未读消息**: 显示未读消息数量（紫色）

#### 最近活动记录
以时间轴形式展示最近的操作记录：
- **操作类型**:
  - ✅ 完成评审（绿色）
  - ✏️ 修改信息（蓝色）
  - 🔐 登录系统（灰色）
- **显示内容**:
  - 操作描述
  - 操作时间（精确到分钟）
- **排序**: 按时间倒序显示最新5条

### 3. 开关控件

## 数据结构

### 用户信息 (userInfo)
```typescript
{
  username: string        // 用户名（不可修改）
  realName: string        // 真实姓名
  email: string          // 邮箱地址
  phone: string          // 手机号
  avatar: string         // 头像URL
  bio: string           // 个人简介（最多200字）
  isAdmin: boolean      // 是否管理员
}
```

### 密码表单 (passwordForm)
```typescript
{
  oldPassword: string      // 当前密码
  newPassword: string      // 新密码
  confirmPassword: string  // 确认密码
}
```

### 账号绑定 (bindings)
```typescript
{
  id: number
  name: string            // 平台名称
  icon: Component         // 图标组件
  color: string          // 主题颜色
  bound: boolean         // 是否已绑定
  account: string        // 绑定账号
}
```

### 登录设备 (devices)
```typescript
{
  id: number
  device: string          // 设备名称
  browser: string         // 浏览器
  os: string             // 操作系统
  location: string        // 登录地点
  ip: string             // IP地址
  time: string           // 登录时间
  current: boolean       // 是否当前设备
  icon: Component        // 设备图标
}
```

### 消息订阅 (subscriptions)
```typescript
{
  id: number
  name: string           // 订阅名称
  description: string    // 功能描述
  enabled: boolean       // 是否启用
}
```

### 通知方式 (notificationMethods)
```typescript
{
  site: string[]         // 站内通知类型
  email: string[]        // 邮件通知类型
  sms: string[]         // 短信通知类型
}
```

### 统计数据 (stats)
```typescript
{
  activities: number     // 参与活动数
  reviews: number        // 完成评审数
  tasks: number          // 待办任务数
  messages: number       // 未读消息数
}
```

### 活动日志 (activityLogs)
```typescript
{
  id: number
  action: string         // 操作描述
  time: string          // 操作时间
  icon: Component       // 图标组件
  color: string         // 标记颜色
}
```

## 安全特性

### 1. 密码安全
- 要求输入当前密码验证身份
- 新密码长度限制（6-20位）
- 确认密码二次验证
- 修改成功后清空表单

### 2. 设备管理
- 显示所有登录设备信息
- 标识当前设备
- 支持移除其他设备
- 异常设备检测提示

### 3. 账号绑定
- 第三方账号绑定/解绑
- 绑定状态实时显示
- 操作确认提示

## 技术实现

- **框架**: Vue 3 Composition API
- **UI库**: Ant Design Vue
- **样式**: Tailwind CSS
- **图标**: Ant Design Icons
- **日期**: Day.js
- **路由**: Vue Router
- **状态**: Pinia Store

## 设计原则

1. **信息分层**: 使用左侧导航清晰划分功能模块
2. **视觉一致**: 统一的卡片样式和配色方案
3. **操作简单**: 每个功能都有明确的操作提示
4. **反馈及时**: 所有操作都有即时的视觉反馈
5. **安全优先**: 敏感操作都需要验证和确认
6. **扩展友好**: 预留接口便于后续功能扩展
